# 航空箱模组（Aircrafte / aircrate）材质需求简报

## 项目背景

这是一个 Minecraft 1.21.1 NeoForge 模组「航空箱」（Air Crate），是「机械动力」（Create 6.0.10）的附属玩法模组。核心玩法：用玻璃航空箱（多方块结构）养生物，配合物流系统（打包机、蛙港、漏斗、皮带）做生物自动化养殖与运输。

**美术风格基调**：必须贴合 Create 模组的设计语言——蒸汽朋克工业风、黄铜/安山岩机壳、铆接金属板、16×16 像素、深色勾边、柔和的明暗层次（不要高饱和赛博风，不要写实风）。

## 参考对象（可在 mcmod.cn 或 CurseForge 搜图）

- **Create 保险库（Item Vault）**：铆接金属边框的结构容器，航空箱的外壳参考它，但要改配色区分
- **Create 流体储罐（Fluid Tank）**：大面积玻璃 + 金属框 + 连接纹理；扳手可以开玻璃窗
- **Create 打包机（Packager）**：蓝灰色边框 + 白色机身 + 红色饰带 + 虹膜封口圆口
- **Create 附属「流体包裹」（Create: Fluid Logistics）的流体打包机**：它把 Create 打包机的蓝灰边框换成了铜橙色——我们的生物打包机要在**同样的位置**换成**黄铜色**（Create 黄铜机壳那种金黄色）
- **流体包裹模组的流体包裹物品**：纸板包裹 + 正面玻璃窗可以看到里面的液体——生物包裹照这个思路
- **原版校频幽匿感测体（Calibrated Sculk Sensor）**：回响激发器的顶部参考
- **原版/Create 过滤器（Filter）**：生物过滤器的造型基础

## 需要绘制的资产清单（共 8 项）

### 方块类（需要六面设计：正/背/左/右/顶/底，16×16 每面）

1. **航空箱 Aviation Crate**（核心方块，可拼成最大 5×3×32 的多方块玻璃箱）
   - 大面积玻璃面（能清楚看到箱内生物），玻璃拼接后视觉连续
   - 外壳：浅色"航空铝"灰蓝金属框 + 黄铜角件/铆钉（不要直接用保险库的深钢色，要明显区分）
   - 侧面是大玻璃，顶/底是金属板
   - 需要一个"扳手开窗"的开放状态变体（玻璃变开口）

2. **交互舱口 Interaction Hatch**（装在航空箱外壁，机械手/玩家通过它挤奶、剪羊毛）
   - 边框与航空箱同族（铝框），中央圆形操作口
   - 口内体现"照顾动物"的功能感（如毛刷、奶滴元素）
   - 其余面为铆接铝板

3. **回响激发器 Echo Resonator**（水晶类机器，范围为生物蛙港供能）
   - 底座：安山岩机壳 + 应力轴/机械传动元素
   - 中部：幽匿（Sculk）深蓝脉络环带，带青色发光脉络
   - 顶部：紫水晶簇（参考校频幽匿感测体）
   - 最好有"激活发光/未激活"两种状态

4. **生物打包机 Creature Packager**（把生物打成包裹）
   - 以 Create 打包机为基础，边框换黄铜色（金黄，Create 黄铜机壳色系）
   - 保留：虹膜封口圆口、指示灯、连接面回纹、红色饰带
   - 有水平/垂直/充能/未充能/联动等状态变体（可先做基础两态）

5. **生物包裹 Creature Parcel**（包裹里有活生物）
   - 纸板箱外壳 + 封箱胶带
   - **正面大面积玻璃窗，能看到里面的生物**（生物本体由代码渲染，图上画出"透明窗+里面隐约有生物"的感觉即可）
   - 拿在手上、丢在地上都长这样

### 物品类（16×16 平面贴图）

6. **混合饲料 Mixed Feed**（由小麦+苹果+任意种子合成，喂生物繁殖用）
   - 设计成**一捆**：麻绳捆扎的谷物束，小麦穗金黄为主，夹红色苹果块和深色种子
   - 不要用碗装（配方里没有碗）

7. **生物过滤器 Creature Filter**（筛选生物种类）
   - 保留 Create 过滤器的特征：长方形、有边框、中间内容区
   - 中间内容改为生物主题（爪印或生物剪影），边框黄铜色

8. **生物收纳器 Creature Catcher**（手持工具，右键生物直接打包成包裹）
   - 本质是"手持的打包机"：黄铜小机身 + 虹膜封口圆口 + 握柄
   - 参考便携式股票终端（Create 的 Portable Stock Ticker）的手持设备感

## 交付要求

- 每项资产出一张工程预览图：3D 效果预览 + 六面视图（物品除外）+ 16×16 各面贴图 + 色板
- 贴图必须是干净的 16×16 像素画（无抗锯齿模糊、无照片纹理）
- 风格统一：同一套黄铜/铝/玻璃色系贯穿全部资产
- 最终需要能导出为 Minecraft 可用的 PNG 贴图（透明背景、逐像素清晰）
